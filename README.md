# Wave

A reflection-first ritual tracking app designed to help ambitious people build sustainable momentum instead of cycling between overachievement and burnout.

## Features

- **75-day challenge** with ongoing ritual tracking after completion
- **Five daily rituals**: Indoor Movement, Outdoor Movement, Nourish, Ground, Grow
- **Daily reflection** with wave intensity and mood tracking
- **Progress calendar** with colour-coded day status
- **Rule-based insights** to understand your patterns
- **Local storage only** — no backend, no authentication

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Local Storage

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
